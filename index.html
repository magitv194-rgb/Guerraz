Reconocimiento de voz: Web Speech API del navegador. Traducción: MyMemory Translation API. Se necesita conexión a Internet y un navegador compatible (Chrome o Edge suelen ofrecer mejor soporte). El audio se procesa mediante el servicio de reconocimiento del navegador; el texto reconocido se envía a MyMemory para traducirlo. Uso gratuito sujeto a límites del proveedor.
